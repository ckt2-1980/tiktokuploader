Política de Privacidade

Este aplicativo utiliza a API oficial do TikTok apenas para permitir o envio de vídeos e gerenciamento de conteúdo.

Não coletamos dados pessoais além do necessário para autenticação via TikTok (OAuth2).

Os dados de login são processados diretamente pelo TikTok e não ficam armazenados neste aplicativo.

Ao usar este serviço, você concorda que sua conta TikTok será vinculada apenas para fins de publicação de conteúdo.

Se tiver dúvidas, entre em contato pelo e-mail: contato@seudominio.com
